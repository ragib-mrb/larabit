# Contributing

Bug reports and pull requests are welcome. For larger changes, please open an issue first so we can agree on the approach.

## Running the tests

    composer install
    composer test

CI runs the suite against every supported PHP and Laravel combination (see `.github/workflows/tests.yml`).

## Pull requests

- Add or update a test for any behavior change.
- Update `README.md` and the `Unreleased` section of `CHANGELOG.md` when the change is user-facing.
- Keep one change per pull request.
