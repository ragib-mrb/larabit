# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 2.x | Yes |
| 1.x | No |

## Reporting a vulnerability

Please don't open a public issue for security problems. Instead, report them privately through GitHub: go to the repository's **Security** tab and choose **Report a vulnerability**.

You'll get a reply within a week. Confirmed issues are fixed in a new patch release and credited in the changelog, unless you prefer to stay anonymous.
