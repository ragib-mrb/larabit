# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, and assume good intent. Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests or any other project space.

## Reporting

Report unacceptable behavior to the maintainer, Ragib Mrb, at ragib.mrb@gmail.com. Reports are handled confidentially. The maintainer may remove comments, close threads or block participants who break this code of conduct.
